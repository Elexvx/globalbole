# 五语言内容与导航

支持简体中文 `zh-CN`、繁体中文 `zh-TW`、英文 `en`、俄语 `ru`、法语 `fr`。

- 首页、桌面与手机页头均显示语言选择入口。根首页使用原生链接与 `details`，不引入 React 水合负担；禁用 JavaScript 仍能切换语言。
- 所有语言网址都可直接打开、刷新和分享。显式语言网址优先；浏览器保存所选语言，再次打开根首页时恢复该选择。存储被禁用时链接继续可用。
- 文章通过 `translationKey` 关联，语言切换保留同篇文章。栏目、刊期、档案与辅助页面保留当前路径。
- 标签按同篇文章中的对应顺序维护译名，切换时进入对应语言的主题页；`hreflang` 与 sitemap 使用这些真实的对应网址。
- 界面翻译在 `lib/messages.json`，辅助说明在 `components/info-view.tsx`。新增界面文案须同步五种语言。
- 正文为每种语言独立 Markdown。标题、摘要、正文、标签、图片说明与来源注释都须翻译；日期、事实、数字、来源 URL 与媒体资产必须保持一致。
- 图片在译文中复用同一原文件，不重复制作。生成式示意图的性质必须在每种语言中明确标注；来源原图保留可见的摄影、来源与授权说明。
- 中文、俄语、法语和英文共享同一字号规范，参见 `viewport-scaling.md`。长标题允许自然换行，表格和代码块只在自身区域横向滚动。
- 各语言 RSS：`/feeds/zh-CN.xml`、`/feeds/zh-TW.xml`、`/feeds/en.xml`、`/feeds/ru.xml`、`/feeds/fr.xml`。

当前两期（2026-10-03、2026-10-04）共 10 个主题，每个主题五种语言，共 50 个 Markdown 文件。每种语言各 10 篇，可完整访问首页、档案、栏目、标签、刊期及正文。译文维护在项目中，不依赖在线机器翻译服务。

## 发布回归

`tests/multilingual.test.mjs` 检查每篇文章五语言完整性、同篇切换、标签译名一致、来源链接、段落标题、脚注与共享图片保留，以及语言偏好脚本的存储失败降级。`npm run check:export` 与 `node scripts/check-seo.mjs` 继续覆盖导出的真实链接、语言元信息、RSS、canonical、互惠 hreflang 和 sitemap。
