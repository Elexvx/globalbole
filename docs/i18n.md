# 五语言适配

支持简体中文 zh-CN、繁体中文 zh-TW、英文 en、俄语 ru、法语 fr。

- 界面翻译：lib/messages.json；补充新控件时同步五种语言。
- 辅助页面：components/info-view.tsx 中的五语言说明。
- 正文：每种语言独立 Markdown，translationKey 关联同篇内容。
- 刊期与栏目：语言切换保留当前路径；文章切换保留同篇内容。
- 日期：构建时使用对应语言的 Intl 日期格式。
- 排版：中文调整字距和行高，俄法长单词允许换行；表格与代码块局部滚动。
- 语言网址可直接刷新和分享，不依赖浏览器缓存。
- RSS：/feeds/zh-CN.xml、/feeds/zh-TW.xml、/feeds/en.xml、/feeds/ru.xml、/feeds/fr.xml。

本次示例为 30 个主题，每个主题五种语言，共六期、150 个 Markdown 文件。每种语言有 30 篇文章：科技 8 篇、创新 15 篇、商业 7 篇，文章档案分为 3 页。示例文本不是实时新闻；语言内容由项目文件维护，不会自动在线机器翻译。
