# 统一字号与响应式阅读

全站采用一套语义字号。首页头条不再使用独立的大号规则；文章、分类、档案、标签、刊期和辅助页面相同层级的标题保持一致。

| 角色 | 640px 及以上 | 640px 以下 | 用途 |
| --- | --- | --- | --- |
| 一级标题 H1 | 2rem / 32px | 1.75rem / 28px | 页面标题、文章标题 |
| 二级标题 H2 | 1.5rem / 24px | 1.375rem / 22px | 栏目标题、正文分节、首页头条 |
| 三级标题 H3 | 1.25rem / 20px | 1.125rem / 18px | 子分节、三级文章卡片 |
| 正文 | 1.125rem / 18px | 1.0625rem / 17px | 长文与文章导语 |
| 摘要与紧凑列表 | 1rem / 16px | 1rem / 16px | 首页摘要、简短新闻列表 |
| 界面 | .875rem / 14px | .875rem / 14px | 语言菜单、普通控件 |
| 注释与元信息 | .8125rem / 13px | .8125rem / 13px | 图片说明、来源、日期 |

像素值以浏览器默认 16px 字号为例。根字号为 `100%`，尊重用户字号与浏览器缩放，不再随着屏幕宽度无限放大。宽屏用布局与留白扩展，主容器最大 96rem；长文仍保留专用阅读栏。

全部字号变量集中在 `app/globals.css` 的 `--type-*` 设计变量中。H1/H2/H3 行高统一为 1.4，正文行高为 1.85，适合中文及俄法长标题。具体卡片只设置间距和颜色，不再根据版面突出程度放大同层级标题。

`tests/viewport-scale.test.mjs` 防止根字号随视口放大，以及页面脱离集中定义的标题规范。实际手机、桌面和长标题视觉检查另见本次发布验收记录；公式测试不能替代浏览器验收。
