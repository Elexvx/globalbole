# 大屏连续缩放

以 1440 CSS px 为编辑版式基准，根字号为 `max(100%, calc(100vw / 90))`。小窗口保持用户默认字号；超过基准宽度后，基于 rem 的容器、文字、留白、卡片和图标连续增大，无 4K / 8K / 16K 封顶。没有 transform 缩放，也不修改浏览器缩放或设备像素比。

主容器仍使用 84rem，以维持版式比例和少量边距，但不再固定在 1344px。固定像素的小字号、强调分隔线和 Lucide 图标已转换为 rem。正文保留阅读栏宽度，其实际尺寸也同步放大。

| CSS 窗口宽度 | 根字号（默认字号16px） | 主容器宽度 |
| --- | --- | --- |
| 1440 | 16 | 1344 |
| 1920 | 21.33 | 1792 |
| 3840 | 42.67 | 3584 |
| 7680 | 85.33 | 7168 |
| 15360 | 170.67 | 14336 |

以上 8K / 16K 数值是 CSS 公式计算值，不是硬件验收。适配依据浏览器 CSS 视口，而非屏幕物理像素；操作系统显示缩放和浏览器缩放会影响 CSS 视口宽度。图片会随布局放大，但原始图片的细节受素材分辨率限制。

## 验证记录

- 浏览器实测 390、1440、1920、3840 CSS px；容器、根字号、小字与图标按比例缩放，无页面横向溢出。
- 五语言首页在 3840px 均无横向溢出。
- 3840px 法语长文正文为 48px，宽表格仍在正文内；中文档案第三页正常显示。
- 390px 回归：根字号保持16px，无页面横向溢出。
- 预览工具将 7680 / 15360px 请求限制为4096px，因此不能将这两项报告成实际8K / 16K画面测试。
- `tests/viewport-scale.test.mjs` 防止连续缩放公式和容器比例回退，包含8K / 16K公式检查。
